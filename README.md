# eleven-cleaner
вам надоел всякий мусор после скачивания windows 11? этот репозиторий для вас! 
## что делает скрипт?
он удаляет прочий microsoft мусор, например: outlook или copilot
## что он удаляет?
microsoft.copilot	- ии помощник

microsoft.windows.outlook	- почта

microsoft.microsofttodo	- список дел

microsoft.microsoftsolitairecollection - пасьянс и казуальные игры

microsoft.microsoft365 - офисный пакет

microsoft.bingweather -	погода

microsoft.bingnews - новости

microsoft.getstarted - начало работы

microsoft.xboxgamingoverlay - игровая панель

microsoft.xboxapp - приложение xbox

microsoft.yourphone - ваш телефон

microsoft.people - люди

microsoft.mixedreality.portal	- смешанная реальность

microsoft.windowsalarms	- будильники

microsoft.windowscamera	- камера

microsoft.windowsSoundRecorder - диктофон

microsoft.mspaint -	paint

microsoft.office.onenote - onenote

microsoft.skypeapp - skype

microsoft.zunemusic -	музыка

microsoft.zunevideo -	видео

microsoft.windows.photos - фото

microsoft.windowsstore - магазин приложений (закоментированно)
## как запустить?
установите clean.ps1 на ваш ПК и запустите файл от имени администратора
